This project started as a way to learn and practise my cyber skills.

It began as a project to set up a self-hosted website from my home lab. Because it was on a budget, I looked at the cheapest ways to host the site.

Hosting on the dark web is free because I do not need to pay a registrar for a domain name. I realised it was a pretty cool thing to be self-hosting my website on the dark web, so I decided to stick with that solution.

There will be many people who cannot, or do not want to, access a dark web website. Also, the dark web is slow.

As such, I have decided to host a clone of this webpage on GitHub Pages. Once the GitHub Pages clone is up and running, I will post the clear web link here.
